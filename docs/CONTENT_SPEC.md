# Спецификация контента Caspian College Hub

Каждый агент создаёт ОДИН файл `content/<slug>.json` строго по схеме ниже.
Язык контента — **русский** (поля `*_ru`), плюс краткие казахские (`*_kk`) и английские (`*_en`)
переводы для НАЗВАНИЙ и ПОДЗАГОЛОВКОВ (`name_*`, `tagline_*`, `title_*` курса). Длинные тексты
(описания, уроки, вопросы) — только на русском, остальные языки оставляй пустой строкой "".

## Тон
Дружелюбный, конкретный, без канцелярита и без воды. Обращение к студенту на «вы».
Пиши так, будто объясняешь первокурснику, который впервые видит этот сервис.
Никаких выдуманных фактов о колледже: если не знаешь точного факта — пиши общими словами.

## Обязательные объёмы
- `course.modules`: **3 модуля**, в каждом **2–3 урока** → всего 6–8 уроков.
- `course.quiz.questions`: **5 вопросов**, у каждого **4 варианта**, ровно один верный.
- `faqs`: 4–6 штук.
- `benefits_ru`: 5–6 строк.

## Валидация перед записью
1. Файл — валидный JSON (`python3 -m json.tool`).
2. Ровно один `is_correct: true` в каждом вопросе.
3. Никаких placeholder-строк вроде «текст урока», «lorem», «TODO».
