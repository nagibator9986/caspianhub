# Caspian College Hub

**Единое окно цифровых сервисов Колледжа Каспийского университета** — платформа, которая
собирает разрозненные сервисы колледжа в одном месте. Каждый сервис здесь не просто ссылка,
а карточка с понятным описанием, ответами на частые вопросы и мини-курсом «как этим пользоваться».

Фирменный стиль взят с [ccu.edu.kz](https://ccu.edu.kz): коралловый `#EB5A40`, акцент `#F9A03F`,
графит `#6D6D6B`, белый.

---

## Быстрый старт

```bash
cd caspianhub
python3 -m venv .venv && source .venv/bin/activate     # необязательно
pip install -r requirements.txt
python seed.py          # создаст базу и наполнит её контентом
python run.py           # http://127.0.0.1:5000
```

## Что внутри

### Публичная часть
- **Главная** — витрина с поиском, категориями, избранными сервисами, курсами, отзывами, новостями и FAQ
- **Каталог сервисов** — фильтрация по категориям, живой поиск, сортировка (всё без перезагрузки)
- **Страница сервиса** — описание, польза, скриншоты, мини-курс, FAQ, ссылка на внешний сервис
- **Мини-курсы** — модули → уроки (Markdown) → итоговый тест → сертификат
- **Новости**, **FAQ**, **О платформе**, **Поддержка** (форма обращений с защитой от ботов)
- **Личный кабинет** — прогресс обучения, избранное, сертификаты, профиль
- Три языка (RU / KK / EN), тёмная тема, адаптивность, поддержка `prefers-reduced-motion`

### Панель управления
Редактируется **всё**, без правки кода:

| Раздел | Что можно |
|--------|-----------|
| Дашборд | Метрики, график активности за 30 дней, топ сервисов, последние обращения и действия |
| Сервисы | CRUD, три языка, иконки, цвета, логотип и обложка, теги, статус, скриншоты, FAQ, порядок перетаскиванием |
| Категории | CRUD, иконка, цвет, порядок |
| Курсы | CRUD курсов, модулей и уроков; Markdown-редактор; тесты с вариантами ответов |
| Новости | CRUD, обложка, тип записи, закрепление, дата публикации |
| FAQ, отзывы | CRUD, категории, порядок |
| Блоки главной | Включение/выключение и тексты каждой секции главной страницы |
| Меню сайта | Конструктор навигации: шапка, подвал, быстрые ссылки |
| Настройки | Бренд-цвета, логотип, тексты первого экрана, контакты, соцсети, SEO, функции |
| Пользователи | Роли, блокировка, смена пароля, сертификаты |
| Обращения | Статусы, внутренние заметки |
| Медиа | Загрузка файлов, копирование путей |
| Аналитика, журнал | Рейтинг сервисов, статистика обучения, история действий |

## Технологии

**Бэкенд:** Flask 3 · SQLAlchemy 2 · SQLite · Flask-Login · Flask-WTF (CSRF) · Flask-Migrate
· Markdown + bleach (безопасный рендеринг) · Pillow (сжатие загрузок)

**Фронтенд:** Tailwind CSS · Alpine.js · GSAP + ScrollTrigger · Lenis · AOS · Swiper
· Lucide · Chart.js · EasyMDE · SortableJS · GLightbox · canvas-confetti · CountUp · Notyf · Vanilla-tilt

Все библиотеки и шрифты (Manrope, Inter) **лежат локально** в `app/static/vendor` и `app/static/fonts` —
платформа полностью работает офлайн, без обращений к CDN.

## Как всё устроено

**Мультиязычность.** У переводимых моделей поля дублируются суффиксами `_ru` / `_kk` / `_en`,
а вывод идёт через `obj.tr('поле')` с откатом на русский. Так каждый язык редактируется прямо
в админке, без внешних `.po`-файлов и перекомпиляции.

**Настройки сайта.** Таблица `settings` — пары ключ-значение с типом (`text`, `color`, `image`,
`bool`, …). Админка сама строит форму по типу поля, а бренд-цвета подставляются в CSS-переменные
`--brand` / `--brand-2` прямо в `<head>` — поэтому смена цвета в админке мгновенно перекрашивает сайт.

**Контент как данные.** Описания сервисов, уроки, тесты, новости и FAQ лежат в `content/*.json`
и заливаются через `seed.py`. Формат описан в `docs/CONTENT_SPEC.md`.

**Безопасность.** CSRF на всех формах, пароли через `werkzeug.security`, Markdown очищается
через `bleach`, загрузки ограничены по типу и размеру (16 МБ), защита от open redirect,
honeypot в форме поддержки, заголовки `X-Content-Type-Options` / `X-Frame-Options` / `Referrer-Policy`.

## Деплой на Railway

Всё уже настроено: `railway.json` (сборка Railpack, старт через gunicorn, healthcheck `/`),
`wsgi.py`, `bootstrap.py` (создаёт таблицы и заливает контент только в пустую базу).

1. **New Project → Deploy from GitHub repo** → выбрать этот репозиторий.
2. В проекте **+ New → Database → PostgreSQL**.
3. В сервисе сайта, вкладка **Variables**:

   | Переменная | Значение |
   |---|---|
   | `DATABASE_URL` | `${{Postgres.DATABASE_URL}}` |
   | `FLASK_ENV` | `production` |
   | `SECRET_KEY` | длинная случайная строка (`python -c "import secrets;print(secrets.token_hex(32))"`) |
   | `ADMIN_EMAIL` | почта администратора |
   | `ADMIN_PASSWORD` | надёжный пароль — применяется при каждом старте |

4. **Settings → Networking → Generate Domain**.

Демо-учётки (`admin@ccu.edu.kz / admin123` и др.) тоже создаются — после запуска смените
их пароли или удалите в админке. Загруженные через админку файлы лежат в
`app/static/uploads` и при редеплое пропадают; чтобы сохранять их, подключите
Volume с путём монтирования `/app/app/static/uploads`.
